# Security policy

MeshShift processes model files locally. Do not upload proprietary model data,
credentials, or unredacted logs when reporting an issue.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the repository's
GitHub Security Advisories page. If private advisories are unavailable, open a
minimal issue asking for a private reporting channel without including
reproduction details or sensitive data.

Include the affected MeshShift version, operating system/architecture, impact,
and a minimal reproduction that contains no customer assets. Allow reasonable
time for investigation and a fix before public disclosure.

Desktop releases include Electron, Chromium, Node.js, and third-party runtime
dependencies. Security fixes may require a new MeshShift release even when the
MeshShift source code itself has not changed.
